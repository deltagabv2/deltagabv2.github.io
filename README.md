# Deltagab — Portfolio

Portfolio statique moderne, prêt pour GitHub Pages.

## Structure

- `index.html` — contenu du portfolio
- `style.css` — design, responsive et animations
- `script.js` — interactions et animations au scroll
- `assets/` — images/logos à ajouter

## Mise en ligne sur GitHub Pages

1. Crée un dépôt nommé exactement `Deltagab.github.io` (ou remplace Deltagab par ton pseudo GitHub exact).
2. Mets les fichiers de ce dossier à la racine du dépôt.
3. Dans GitHub : **Settings → Pages**.
4. Choisis **Deploy from a branch**, branche `main`, dossier `/ (root)`.
5. Ton site sera disponible sur `https://TONPSEUDO.github.io`.

## À personnaliser

- Remplace les liens `https://github.com/` par tes vrais dépôts.
- Remplace `contact@deltagab.fr` par ton adresse e-mail.
- Ajoute tes images dans `assets/`.
- Tu peux modifier les couleurs dans `:root` de `style.css`.
